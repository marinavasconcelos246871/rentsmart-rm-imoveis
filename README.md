# RentSmart - Sistema de Orçamento de Locação

Projeto desenvolvido em Python utilizando Programação Orientada a Objetos para calcular orçamentos de aluguel da R.M Imóveis e gerar a projeção de 12 meses em CSV.

## Como rodar o projeto

1. Tenha o Python 3 instalado na máquina.
2. Abra o terminal na pasta do projeto e execute:

```bash
python main.py
